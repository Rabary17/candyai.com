## Comment nous avons choisi ces alternatives

Chaque application a suivi le protocole de notre test de Candy AI : compte payant, même script quotidien, cinq critères pondérés, décrits dans [notre méthode de test](/fr/methode-de-test/). **Nous y ajoutons un test du français** : compréhension, tutoiement spontané, expressions courantes, voix française. Les applications sans société identifiable ou disponibles seulement en APK non officiel sont exclues.

Les commissions d'affiliation ne décident pas du classement : certaines applications nous rémunèrent, d'autres non, et toutes figurent avec les mêmes colonnes.

## 2. Replika : pour une relation amicale

Replika, lancée en 2017 par Luka Inc., mise sur l'amitié, la conversation et le suivi de l'humeur plutôt que sur les visuels. **Elle ne génère pas d'images de votre compagnon.** La version Pro coûte environ 19,99 $ par mois, ou 69,99 $ par an. Le duel complet : [Candy AI ou Replika](/fr/vs/candy-ai-vs-replika/).

## 3. Character AI : la meilleure option gratuite pour le jeu de rôle

Character AI héberge des millions de personnages créés par les utilisateurs. La discussion est gratuite ; **le contenu adulte est filtré** et les règles pour les plus jeunes ont été durcies. Idéal pour le jeu de rôle et l'écriture, moins pour la romance. Voir [Candy AI ou Character AI](/fr/vs/candy-ai-vs-character-ai/).
